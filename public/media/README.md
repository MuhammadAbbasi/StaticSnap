# StaticSnap Brand Media & Identity Kit

Welcome to the official brand media repository for **StaticSnap**. This directory contains all official logos, icons, vectors, favicons, and social preview assets for the project.

---

## 1. Brand Logo Concept & Symbolism

The **StaticSnap** brand mark is an abstract geometric synthesis representing the core function of the engine:

- **The 'S' Monogram:** Interlocking geometric shutter blades naturally form an angular, modern letter **"S"**.
- **The Camera Shutter / Aperture ("Snap"):** Represents instant web capture, real-time telemetry streaming, and visual diagnostic snapshots.
- **The Central Isometric Cube ("Static"):** At the focal point of the shutter is a crystalline, solid isometric cube representing the frozen, self-contained static bundle that runs anywhere without an origin server.
- **Color Duality:** 
  - **Dynamic Orange (`#f97316` / `#fbbf24`):** Represents dynamic motion, speed, crawler energy, and real-time live processing.
  - **Electric Blue (`#0284c7` / `#38bdf8`):** Represents stability, rock-solid static preservation, clean code architecture, and reliability.

## 5. Usage Guidelines

- **Do:** Use the SVG or high-resolution PNG on dark or neutral backgrounds (`#090d16`, `#0f172a`, `#1e293b`).
- **Do:** Maintain the clear space around the logo mark equal to at least 25% of the mark's total width.
- **Don't:** Rotate the mark or alter the angle of the shutter blades.
- **Don't:** Swap or alter the contrast balance between the orange upper shutter and blue lower shutter.
